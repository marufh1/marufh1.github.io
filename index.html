About

Maruf HossainSr. Software Engineer, Grapes Technology

I'm a full-stack engineer based in Dhaka, Bangladesh, with six-plus years building web applications end to end — from database schema and API design through to the interfaces people actually use. That work spans two ecosystems: ASP.NET Core and SQL Server for fintech, government, and enterprise systems, and React, Node.js, and MongoDB for full-stack consumer products like car rental and food-ordering platforms.

Early in my career at Advanced Software and IT Services, I worked across ASP.NET MVC, Web Forms, and SQL Server on government and enterprise systems — including a land survey platform integrated with government web services — while mentoring junior developers and working closely with the CTO on delivery. At Siara Solutions, I led full-stack development in React, Node.js, and TypeScript for car rental, food-ordering, and online tutoring platforms, adding real-time chat and third-party integrations. I now focus on ASP.NET Core and React at Grapes Technology, building a fintech platform that includes mobile-money integrations and SQL Server performance work.

Selected Work

Case studies from production systems

Four projects spanning full-stack product platforms, fintech, government systems, and enterprise workflow tools.

Car Rental & Food-Ordering Platforms

E-commerce & rental
Problem

Three consumer products — vehicle rental, online food ordering and restaurant management, and online tutoring — needed real-time features and reliable third-party integrations on tight timelines.

What I contributed

Led full-stack development in React, Node.js, and TypeScript as team lead; built backends on PostgreSQL and MongoDB; implemented real-time chat with WebSocket/Socket.io; integrated Brevo, Infobip, and Mapbox; and added secure Jitsi video conferencing for tutoring sessions.

Key technologies React, Redux, Node.js, Express.js, TypeScript, PostgreSQL, MongoDB, Socket.io
Outcome

Delivered as team lead across three concurrent product lines, from data modeling through to shipped, real-time features.

Details

Each platform shared a Node.js/Express/TypeScript API layer with product-specific data stores — PostgreSQL for relational data, MongoDB where schema flexibility mattered — with React front ends split between MUI and Ant Design depending on the product.

Fintech Transaction Platform

Financial systems
Problem

Fintech platforms need transaction and reporting workflows that stay accurate and fast as data volume grows — and that can plug into local mobile-money rails.

What I contributed

Architecting and maintaining core platform modules, optimizing SQL Server queries, indexing, and stored procedures, and integrating mobile financial service providers including Safaricom M-Pesa and GeePay.

Key technologies ASP.NET Core, C#, SQL Server, React, REST APIs
Outcome

Reduced execution time on critical reports and improved scalability and reliability by refactoring legacy modules and database design.

Details

The platform separates transaction processing and reporting into layered modules on top of SQL Server, with stored procedures handling the heaviest aggregations and mobile-money providers integrated behind a common service interface.

Government Land Administration Systems

Public sector
Problem

Land survey and land case records needed a maintainable, government-integrated web system to support administration and case tracking.

What I contributed

Built a land survey web application (settlement.gov.bd) on ASP.NET MVC with integrated government web services, and developed a separate land case management system on ASP.NET MVC and SQL Server.

Key technologies ASP.NET MVC, SQL Server, government web services
Details

Both systems were built as multi-user ASP.NET MVC applications backed by SQL Server, with the survey platform consuming external government web services for record handling.

Audit, ERP & Workflow Systems

Enterprise workflow
Problem

Manual audit tracking, leave requests, and duty-shift scheduling created overhead inside an existing enterprise ERP.

What I contributed

Designed an audit management system in ASP.NET Core using stored procedures, and enhanced the ERP with leave and duty-shift modules, while also contributing to hospital management system modules and maintaining legacy ASP.NET Web Forms code.

Key technologies ASP.NET Core, SQL Server, Stored Procedures, ASP.NET Web Forms
Outcome

Streamlined workflow automation and reporting across audit and workforce-management processes.

Details

The audit module relied on stored procedures for heavier reporting logic, while the ERP enhancements extended an existing ASP.NET Web Forms codebase without disrupting production workflows.
